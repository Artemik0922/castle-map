# 🏰 Замок на скале — карта локации на Three.js

Одна страница, один сид, ноль зависимостей кроме Three.js: процедурная локация для top-down игры — крепость на скале, город за стеной, река с мостом и пристанью, поля, карьер, дозорные башни, казарма с батареей, полигон с разрушаемыми стенами и вторжение, которое можно отбить.

Всё генерируется из числа: повороты стен, форма скалы, герб и цвета фракции, количество башен, стиль крыши, раскладка полей и дорог. Клавиша `N` — и у вас уже другой замок в другой стране.

**Репозиторий:** https://github.com/Artemik0922/castle-map · локально — `npm start` → http://127.0.0.1:4300/

---

## 🚀 Запуск

Никакой сборки нет, нужен только Node (модули ES + importmap, Three.js лежит в `vendor/`).

```bash
npm start       # node tools/serve.mjs → http://127.0.0.1:4300/
npm test        # 35 проверок баллистики и модели боя, без браузера
```

Открывать просто `index.html` двойным кликом нельзя — браузер не даст загрузить ES-модули с `file://`. Нужен любой статический сервер.

## 🎮 Что там можно покрутить

| Клавиша | Действие |
| --- | --- |
| `W A S D` / `Q E` | сдвиг и поворот камеры |
| `R` | сброс камеры |
| `T` | режим карты (вид сверху) |
| `O` | автооблёт |
| `B` / `G` | подъёмный мост / решётка ворот |
| `V` / `K` | залп взвода / залп батареи казармы |
| `F` | выстрел с полигона по мишеням |
| `I` | начать вторжение |
| `N` | новая локация (новый сид) |
| `1` `2` `3` `4` | утро / день / закат / ночь |
| `H` | спрятать панель |

Панель слева — это, по сути, редактор: время суток, азимут солнца, наклон и высота камеры, что показывать (тени, жители, огонь и дым, каркас), и переход по участкам локации — Замок, Город, Пристань, Поля, Карьер, Лагерь, Казарма, Полигон, Поле боя, Вся карта.

## 🌱 Город растёт в реальном времени

Хроноика считает календарь: **1 игровой год = 1 реальный сутки** на минимальной скорости, на максимальной — год за минуту. Ползунок скорости, пауза, и лог событий.

Каждый участок — дом, мастерская, загон, поле, сад, часовня, колодец, ветряк, флигель казармы — появляется, когда приходит его очередь, и сразу перекраивается под сезон: листва, тон травы, дым из труб. Застройка не пересобирает мир: участок строится лениво, вливается в общий меш и показывается с pop-in, поэтому кадры в секунду не падают по мере роста города. Ползунок темпа поднимается до года за минуту — третий квартал не придётся высидеть сутки.

## 💥 Полигон: настоящая баллистика

Три орудия на площадке, три разрушаемые стены-мишени (6×3, 7×4, 5×5 блоков).

Угол возвышения решается аналитически — квадратное уравнение `k·t² − d·t + (k+dh) = 0` для навесной траектории, дальше снаряд летит с ускорением 30 м/с², начальной скоростью 95 м/с и сопротивлением 0.004, с подшагами по 1/30 секунды. Попадание снимает блоки в радиусе, трещина растёт, секция осыпается: обломки, пыль, воронки, копоть. Кучность проверяется тестом — при разбросе ±0.45 м/с не меньше 80 % снарядов должны лечь в цель.

Ствол наводится и по азимуту, и по возвышению, так что видно, как расчёт работает.

## ⚔️ Вторжение

Модель боя отделена от рендера: `army.js` — это чистые числа, без Three.js, и она считается в ноде.

Пехота, конница, орудия и обоз с реальной дальностью, моралью и залпами. Фазы: **сбор за гребнем → колонна на подходе → развёртывание в линию → штурм → отбито / сломлена**. Дозорные башни зажигают костры, когда появляется враг. Колонна разворачивается в линию, а не сваливается в точку: у каждого отряда своё место в строю и своя глубина.

Орки-атакующие в красных кафтанах, гарнизон в синих; ядра летят по той же баллистике, что и на полигоне. Исход считается по остаточной силе сторон, после боя разбитая сторона обращается в бегство и уходит с поля.

## 🧮 Оптимизация

Цель — чтобы вся карта крутилась на слабом железе. Что дало результат:

- **`mergeStatic()`** запекает статику в один меш на материал: крепость, город, деревня — это единицы draw call вместо тысяч. Мелкие `InstancedMesh` (≤64 экземпляра) вливаются в тот же батч, а их поштучные цвета сохраняются как vertex colors.
- **Инстансинг всего живого** — трава, деревья, кусты, камни, люди, скот, птицы, солдаты. Один меш на отряд, `mesh.count` равен текущей численности.
- **Ленивые LOD-группы** — дальний план включается только когда он в радиусе, ближнийdetail — когда камера близко.
- **Замороженная карта теней** — `shadowMap.autoUpdate = false`, перерисовка только когда свет или сцена действительно изменились.
- **Адаптивный `devicePixelRatio`** — если кадры поехали, разрешение падает само.
- **Пул огня и дыма** — все костры, факелы и трубы рисуются двумя `InstancedMesh` за кадр, а не спрайтами на каждый огонь.
- **Террейн чанками 4×4** и одна высота-функция на всю карту: аналитический height field, никакой загрузки карт.
- **Кэш геометрий** в `parts.js` — одинаковые бочки, столбы и зубцы не плодят вершины.

Замер на всей карте, 1080p: **≈8.6 мс/кадр, ~450 draw calls**; после 34 отстроенных участков — ≈10.9 мс, ~617 вызовов. Один новый дом стоит ~0.07 мс кадра.

## 🗂 Как устроено

```
index.html            панель управления, стили, importmap
vendor/               three.module.js (r169), лежит в репозитории
tools/serve.mjs       статический сервер, PORT 4300
tests/                баллистика (21) и модель боя (14), чистая нода

src/
  main.js             сборка мира, кадры, горячие клавиши, HUD
  layout.js           раскладка: дороги, зоны, реки, пруд, карьер, высота
  environment.js      террейн чанками, вода, пена, биомы, атмосфера
  location.js         город, стены, поля, пристань, лес, лагерь осаждающих
  castle.js           крепость: скала, стены, башни, донжон, портал
  buildings.js        дома, мастерские, капелла, ветряк, колодец
  parts.js            типовые детали: башни, стены, бочки, знамёна, факелы, пул огня
  textures.js         canvas-текстуры (камень, доски, черепица, солома, земля, вода) и шум/fbm
  materials.js        материалы из этих текстур: камень, дерево, листва, металл, вода, спрайты
  geometry.js         ribbon-геометрия, splitBySize, mergeStatic
  agents.js           инстансинг толпы: фигуры, четвероногие, птицы
  life.js             стада, птицы, крестьяне, жители
  barracks.js         казарма, батарея, строевая подготовка
  range.js            полигон: орудия, разрушаемые стены, обстрел
  ballistics.js       физика снаряда без Three.js
  army.js             модель боя без Three.js
  invasion.js         вторжение: фазы, построение, бой на карте
  chronicle.js        календарь, рост застройки, сезоны, события
  camera-rig.js       pan/tilt/zoom, клавиатура, автооблёт
  lighting.js         пресеты времени суток, тени, туман
  runtime.js          общий тик кадра, чистка сцены, damp
```

Слой данных (`layout.js`) не знает про рендер, слои модели (`ballistics.js`, `army.js`) не знают про Three.js — поэтому баллистику и бой можно тестировать в ноде, а не глазами в браузере.

## ✅ Проверено

35 автотестов в ноде: монотонность возвышения по дистанции и высоте, решение попадает в цель, кучность, AABB-попадания по стене, обрушенная секция не принимает попадания, свободное падение ≈ ½gt², сопротивление тормозит. Отдельно — что отряд доходит по маршруту, залпы дают потери, вне дальности тишина, орудия бьют через всю площадь, низкая мораль обращает в бегство, один сид даёт один результат, обоз не стреляет.

Визуальная часть проверена скриншотами в Chrome на каждом этапе; в проде это, к сожалению, не автоматизируется.

## 🔧 Хочешь поменять

Мир целиком определяется сидом — `makeConfig(seed)` в `src/castle.js` и `makeLayout(cfg)` в `src/layout.js`. Константы боя и баллистики — `KINDS` в `army.js` и `GRAVITY / MUZZLE_SPEED / DRAG` в `ballistics.js`. Скорости хроноики — `SPEED_STEPS` в `main.js`.
